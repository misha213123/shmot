# DRIPLY Documentation

This directory contains product and engineering documentation.

## Canonical files

- `MASTER_EXECUTION_PLAN.md` — ordered sprint plan and completion log.
- `CODEX_WORKFLOW.md` — exact workflow Codex must follow.
- `01_VISION.md` — product mission and positioning.
- `04_MVP.md` — MVP scope and exclusions.
- `07_RECOMMENDATIONS.md` — recommendation approach.
- `10_ARCHITECTURE.md` — architecture notes.
- `14_DEPLOYMENT.md` — deployment guidance.

## Rules

- Do not create a second roadmap or second Codex instruction file.
- Update `MASTER_EXECUTION_PLAN.md` instead of adding ad-hoc TODO documents.
- Keep implementation details in the most relevant existing document.
- Remove documents that duplicate a canonical file.
- `AGENTS.md` remains in the repository root because Codex discovers repository instructions there; it should only point to the canonical documents in this folder.
