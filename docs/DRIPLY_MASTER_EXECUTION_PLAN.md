# DRIPLY — MASTER EXECUTION PLAN

> Главный технический план доведения DRIPLY от текущего состояния до стабильного закрытого запуска.
>
> Репозиторий: `misha213123/shmot`
>
> Основное правило: выполняем этапы строго по порядку. После каждого блока обновляем чек-лист, запускаем проверки и делаем отдельный коммит.

---

## 0. Как работать по этому документу

### Обязательный цикл для каждой задачи

1. Изучить связанные файлы и зависимости.
2. Зафиксировать текущее поведение.
3. Внести минимальное изменение без временных DOM-патчей.
4. Запустить frontend build и backend tests.
5. Проверить на мобильном экране и в Safari/Telegram WebView.
6. Обновить чекбокс в этом файле.
7. Сделать отдельный понятный коммит.

### Запрещено

- добавлять новые `MutationObserver`, если задачу можно решить React-компонентом;
- вставлять стили через JavaScript;
- исправлять layout глобальными `!important` без крайней необходимости;
- дублировать поиск, фильтры, чат или навигацию в нескольких реализациях;
- переходить к новому этапу при незакрытых критических ошибках прошлого этапа;
- менять рабочий функционал, который не относится к текущей задаче.

### Формат коммитов

```text
refactor(frontend): split marketplace screens
fix(navigation): restore mobile bottom bar taps
feat(auth): add Telegram initData validation
feat(chat): add unread message state
test(api): cover product lifecycle
docs(plan): update completed tasks
```

# ЭТАП 1 — СТАБИЛИЗАЦИЯ АРХИТЕКТУРЫ

## Цель

Убрать источник постоянных регрессий: runtime-модули, которые после рендера React ищут элементы через `document.querySelector`, перемещают DOM, добавляют обработчики и динамические стили.

## Критерии завершения этапа

- все основные экраны являются React-компонентами;
- нижняя навигация управляется только React;
- нет дубликатов интерфейсных блоков;
- поиск, рекомендации, чат, сделки и уведомления не вставляются через DOM;
- все основные страницы прокручиваются;
- все кнопки нижней панели работают на iPhone;
- `npm run build` проходит без ошибок;
- ручная проверка всех экранов завершена.
